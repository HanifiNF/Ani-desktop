Subtitle appearance joins the draft, so cancel and save cover it like everything else. Nothing "saves automatically" in a page that has a save button.

S2 · Subtitles fold into Playback as one row. Closed, the row shows a live thumbnail and a one-line summary; open, the same compact controls as S1 slide out beneath it. The page loses the save bar: every row applies on change and a quiet "saved" line replaces it, which is what the subtitle block already does. The right nav shrinks to five sections.

S3 · Rail and pages. Eight headings become five pages on a left rail; only one page is in view, so nothing needs a scroll-spy or a jump menu. Player holds playback and subtitles together. Each page applies on change; the rail's foot carries the version and the update check. This is the biggest change and the calmest page.
